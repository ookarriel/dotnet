# Trabajo 2: API RESTful (Construcción de Software)
**Docente:** Enso Guidotti | **Fecha:** 26-10-2026 | **Modalidad:** Individual

## Enunciado
Crear un sistema de gestión de recursos con API RESTful basado en un caso de negocio real validado previamente por el docente. Aplicar Unidad 2: diseño de endpoints, ORM (EF Core), versionamiento, documentación y seguridad. Al finalizar, realizar exposición individual.

## Requisitos Clave
- **Arquitectura:** ASP.NET Core Web API (con Controladores, no Minimal API), middleware propio, Inyección de Dependencias con scopes adecuados.
- **CRUD:** Completo para recurso principal, verbos/rutas REST, códigos de estado, validación y manejo de errores.
- **Datos:** Entidades mapeadas, DbContext, migraciones y patrón Repository.
- **Docs & Versiones:** API versionada y Swagger.
- **Seguridad:** Login JWT y roles (mínimo 2). Secretos en variables de entorno.
